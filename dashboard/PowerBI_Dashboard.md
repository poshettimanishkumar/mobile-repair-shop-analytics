# Power BI Dashboard

## Dashboard Overview
This dashboard provides insights into the Mobile Repair Shop Analytics project using Power BI.

## Dashboard Visuals
- Total Repairs by Phone Brand
- Repair Status Distribution
- Profit by Store Branch

## KPIs
- Total Repairs
- Total Profit
- Average Customer Rating

## Purpose
The dashboard helps analyze repair performance, profitability, and service status to support business decision-making.

## Tools Used
- Power BI
- MySQL
- Python
- Excel
