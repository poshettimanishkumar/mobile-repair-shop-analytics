# Mobile Repair Shop Analytics

## Project Overview
This project analyzes mobile repair shop operations using Python, MySQL, Excel, and Power BI. The objective is to understand repair trends, customer behavior, profitability, and service performance through data analytics.

## Tools Used
- Python
- MySQL
- Excel
- Power BI

## Dataset
- Mobile Repair Shop Synthetic Dataset
- Total Records: 20,000

## Project Workflow
1. Data Collection
2. Data Cleaning
3. Data Analysis using Python
4. SQL Queries and KPI Analysis
5. Power BI Dashboard Creation
6. Business Insights and Recommendations

## Dashboard Pages
- Overview
- Trends
- Segments

## Key KPIs
- Total Repairs
- Total Repair Cost
- Total Profit
- Average Customer Rating
