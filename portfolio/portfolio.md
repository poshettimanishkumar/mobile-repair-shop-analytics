# Mobile Repair Shop Analytics Portfolio

## Project Title
Mobile Repair Shop Analytics

## Objective
Analyze mobile repair shop operations to identify repair trends, profitability, customer satisfaction, and technician performance using data analytics.

## Tools Used
- Python
- MySQL
- Excel
- Power BI
- GitHub

## Dataset
Mobile_Repair_Shop_Synthetic_Dataset_20000.csv

## Project Workflow
1. Data Collection
2. Data Cleaning
3. Exploratory Data Analysis
4. SQL Analysis
5. Power BI Dashboard
6. Business Insights
7. Documentation

## Key KPIs
- Total Repairs
- Total Profit
- Average Repair Cost
- Completed Repairs
- Pending Repairs
- Customer Rating

## Dashboard Pages
- Overview Dashboard
- Profit Analysis
- Repair Performance
- Customer Analysis

## Key Insights
- Most repairs were completed successfully.
- Profit varied across store branches.
- Some brands generated more repair requests than others.
- Customer ratings remained generally high.
